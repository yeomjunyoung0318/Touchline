스쿼드 전체 예산

매각은 성사 가정으로만 반영해요. 고정 선수·필요한 커버·선수층을 보호하고, 매각 선수를 제외한 배치안을 제안합니다.

한도를 입력하면 사파·커버를 함께 배치하는 영입 조합을 비교해요. 주급은 기존 선수와 감독 구단 소속 선수까지 포함합니다. 빈칸은 해당 한도 없음, 0은 지출 불가예요.

경기장의 자물쇠를 누르면 추천 시 그 선수와 위치를 유지해요.

전체 예산을 설정하면 선발 보강과 사파 커버를 함께 계산하고, 후보·예비는 기존 선수로 구성해요. 스카우팅의 1인 예산과는 별도입니다.

스탯 계산기

포지션을 바꿨을 때의 OVR와 목표 수치까지 필요한 스탯을 비교하세요.

FC27 DB 학습 가중치 추정

실제 게임 수치가 아닌 계획용 추정치입니다. EA의 공식 OVR 계산식은 적용하지 않았습니다. PS5 세이브를 읽거나 게임에 자동 적용하지 않으며, 게임 속 훈련·성장·포지션 전환 결과를 보장하지 않습니다.

현재 세부 스탯

직접 입력한 값이 계산 기준이 됩니다. 빈칸은 미입력으로 취급하며, 선수 원본은 변경하지 않습니다.

추정 방식 자세히 보기

포지션 점수 = 해당 포지션의 세부 스탯 가중 평균.
전환 OVR 추정 = 입력 OVR + 목표 포지션 점수 − 주 포지션 점수.
변경 후 추정 = 입력 OVR + 변경 후 목표 포지션 점수 − 변경 전 주 포지션 점수.

주 포지션과 목표 포지션 계산에 필요한 스탯이 있어야 계산됩니다. 스탯은 1~99 범위에서 조정하며, POT·체형·개인기·약발·플레이스타일·게임의 내부 보정은 반영하지 않습니다.

성장의 방향을 찾아보세요.
