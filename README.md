# Touchline · FC 27 커리어 스쿼드 빌더

**선수 검색부터 전술 배치, 영입 예산, 육성 계획까지 한곳에서 비교하는 한국어 개인용 축구 커리어 도구입니다.**

브라우저에서 스쿼드를 만들고, FC IQ 역할과 포지션별 OVR 추정을 확인하며, 선택적으로 OpenAI 기반 축구 상담을 사용할 수 있습니다. 게임 파일이나 실제 세이브를 수정하지 않는 로컬 웹 앱입니다.

**실제 선수 DB와 DB 기반 영입·스쿼드 추천에는 본인의 FCRadar API 키와 선수 DB 적재가 필요합니다.** FCRadar의 해당 프로젝트·계정에 대한 승인과 이용 약관 충족도 필요하며, 키만 있으면 누구나 사용할 수 있다는 뜻은 아닙니다. 실제 선수 데이터는 저장소에 포함하지 않으며 자동으로 내려받지 않습니다. 새 PC에서는 선수 0명으로 시작합니다. AI 상담에는 별도로 OpenAI API 키가 필요합니다.

## 무엇이 달라지나요?

- **판단에 필요한 정보를 한 화면에:** 선수 검색, 스쿼드 보드, 역할·포커스, 비교 보고서를 연결합니다.
- **예산 안에서 영입 계획:** 이적료·주급, 사파 전환과 커버 선수, 예상 매각 수익을 함께 비교합니다.
- **육성 계획을 구체적으로:** 성장 유형과 기간, 목표 포지션 OVR 및 능력치 변경안을 계산합니다.
- **계산과 대화를 연결:** AI 상담이 로컬 계산 도구를 사용하고, 제안을 검토한 뒤 보드에 반영할 수 있습니다.
- **내 기록은 직접 보관:** 브라우저 자동 저장과 JSON 백업·복원을 지원합니다.

계산값은 계획을 돕는 추정이며 실제 게임의 성장·협상 가격·경기 결과를 보장하지 않습니다.

> 화면 예시와 QA 자료는 공개 전 별도 검토 대상입니다.

## 빠른 시작: 다른 PC에서도 실행하기

필수 환경은 **Node.js 20 이상**과 최신 브라우저입니다. 별도 npm 패키지 의존성은 없습니다. 전체 프로젝트 폴더를 내려받아 압축을 풀거나 저장소를 복제한 뒤, 그 폴더에서 실행하세요.

```sh
node --version
npm run build
npm start
```

브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:4267`에 접속하세요. 종료할 때는 같은 폴더에서 `npm stop`을 실행합니다. Windows에서는 `시작.cmd`와 `종료.cmd`도 사용할 수 있습니다. 특정 PC의 Codex 설치는 필수 조건이 아닙니다.

단순 스쿼드 편집과 계산은 `index.html`을 직접 열어도 됩니다. AI 상담과 선수 데이터 API 기능은 로컬 서버 실행이 필요합니다. 파일 직접 열기와 로컬 서버는 저장 공간이 다르므로 이동 전 **백업 저장**으로 JSON을 내보내세요.

## 선택 기능 설정

`.env.example`을 `.env`로 복사하고 필요한 항목만 직접 입력하세요. Windows PowerShell은 `Copy-Item .env.example .env`, macOS/Linux는 `cp .env.example .env`를 사용합니다. 이미 `.env`가 있다면 덮어쓰지 마세요.

| 환경변수 | 용도 |
| --- | --- |
| `OPENAI_API_KEY` | AI 축구 상담에 필요한 본인 OpenAI API 키 |
| `OPENAI_MODEL` | 계정에서 사용 가능한 모델. 예제 기본값은 `gpt-6-luna` |
| `OPENAI_REASONING_EFFORT` | 추론 강도. 기본값 `medium` |
| `PORT` | 로컬 포트. 기본값 `4267` |
| `FCRADAR_API_KEY` | 선수 데이터 API 조회 및 로컬 DB 구축 |
| `FCRADAR_IMAGE_CDN_BASE_URL` | 승인된 계정의 선수 사진 CDN 주소 |

OpenAI API 키는 각 사용자가 본인 계정에서 준비하며 API 사용 비용도 해당 계정에 청구됩니다. 키를 저장소·스크린샷·채팅·클라이언트 HTML에 넣거나 타인에게 공유하지 마세요. `.env`는 로컬에서만 보관하세요.

API 이용에는 별도 계정·권한과 비용이 발생할 수 있습니다. 모델 사용 가능 여부와 요금은 각 제공자에서 확인하세요. 키가 없는 상태에서도 로컬 스쿼드 편집과 계산을 사용할 수 있지만 실시간 데이터 및 AI 기능은 제한됩니다. 실제 선수 DB는 배포에 포함하지 않으며, 사용 권한이 있는 FCRadar 키로 앱의 선수 검색·DB 구축 기능을 사용하세요.

### 실제 선수 DB 준비

1. [FCRadar API 약관](https://fcradar.gg/api-terms)을 확인하고, 이 프로젝트의 사용 목적에 맞는 관리자 승인과 계정·API 권한을 확보한 뒤 `.env`의 `FCRADAR_API_KEY`에 본인 키를 직접 저장합니다. 발급·승인이 보장되는 것은 아니며 기존 키도 다른 프로젝트로 임의 공유·전용할 수 없습니다.
2. `npm start`로 실행한 페이지에서 **선수 검색 → 선수 DB 적재**를 누릅니다. 시작만으로 DB를 자동 적재하지 않습니다.
3. 화면에서 적재 완료와 선수 수를 확인합니다. 활성 스냅샷을 페이지 단위로 받아 로컬 `data/fc27-players.json`을 생성합니다. 완료 전에는 전체 DB 기반 기능이 제한됩니다.
4. 이후 DB 기반 검색·필터·영입 및 스쿼드 추천을 사용합니다. 갱신은 같은 화면의 **스냅샷 갱신**으로 실행합니다.

**검증 범위:** 이 안내는 코드의 실행·적재 절차를 설명합니다. 심사위원 계정의 키 발급·승인 여부, 실제 키를 통한 API 접속·DB 적재 성공 및 사진 CDN 권한은 확인하지 않았습니다.

데이터 제공자의 계정·API 권한과 이용 조건을 먼저 확인하세요. FCRadar API 약관 제4항은 승인 요청에 기재한 특정 기존 프로젝트의 운영·유지·개선만 허용하며, FCRadar와 실질적으로 유사한 별도 커리어 DB·선수 검색·비교 제품/서비스를 만드는 용도도 제한합니다. 이 코드의 공개 자체가 이 프로젝트의 API 사용 승인을 의미하지 않습니다. 목적이 크게 바뀌면 사용 전에 제공자에게 확인해야 합니다. API 실제 이용 권한과 반환 데이터·이미지의 공개 재배포 권리는 별도입니다. API 접근 권한이 데이터나 이미지를 공개 재배포할 권한을 뜻하지 않습니다. 이 저장소는 실제 DB와 재배포 권리가 확인되지 않은 성장 lookup을 포함하지 않습니다. 성장 lookup이 없으면 해당 출처의 성장 유형 자동 표시가 제한되며 앱 자체는 실행됩니다.

### 키 없이 가능한 범위

- 수동 선수 추가, 본인이 준비한 JSON/CSV 가져오기, 스쿼드 배치·역할 설정, 스탯 계산, 백업·복원은 가능합니다.
- 처음에는 등록 선수가 없으므로 직접 추가하거나 가져와야 합니다. 가상 선수 시연 데이터를 자동으로 넣지 않습니다.
- 실제 선수 전체 DB 검색·고급 필터·DB 기반 추천은 DB 적재 전 사용할 수 없습니다. AI 상담은 OpenAI 키 없이 사용할 수 없습니다.
- 아래 `--mock` 명령은 개발용 모의 연결 시험일 뿐입니다. 실제 선수 DB 기반 추천의 대체 체험이 아니며 콘솔에 출력되는 임의 포트 주소로 접속합니다.

## 개발과 검증

```sh
npm run build   # src/를 하나의 index.html로 묶기
npm test        # Node 내장 테스트 러너 실행
node server.cjs --mock  # 유료 API 없이 연결 흐름 확인
```

`src/`는 화면과 계산 로직, `server/`는 AI·데이터·커리어 계산, `tools/`는 실행·빌드 도구, `tests/`는 자동 테스트입니다. 상세 기능과 사용법은 [사용 가이드](docs/user-guide.md)를 참고하세요. Mock과 자동 테스트 통과는 실제 API 계정·권한·네트워크 연결 성공을 의미하지 않습니다.

## 보안과 데이터 주의사항

- 서버는 `127.0.0.1`에만 연결하는 **개인용 로컬 앱**입니다. 공개 서버 배포나 다중 사용자 운영용이 아닙니다.
- `.env`, API 키, 실행 로그, 실제 선수 DB, 개인 JSON 백업을 저장소에 올리지 마세요. 키는 브라우저가 아닌 로컬 서버에서 사용합니다.
- AI 기능은 질문과 필요한 스쿼드 문맥을 OpenAI에 전송합니다. 중요한 개인정보나 비밀은 입력하지 마세요.
- 선수 데이터·사진·성장 자료는 원 제공자의 이용 조건을 확인해야 합니다. API 이용 권한이 데이터 재배포 권한을 뜻하지는 않습니다.
- EA 또는 데이터 제공자의 공식 제품이 아닌 개인 프로젝트입니다. 외부 자료·상표·이미지의 권리는 각 권리자에게 있습니다. 별도 라이선스가 명시되지 않은 자료의 재사용 권한을 가정하지 마세요.
